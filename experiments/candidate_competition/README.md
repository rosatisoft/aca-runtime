\# Experiment 03 — Candidate Competition



Status:

Experimental



\---



\## Objective



Evaluate multiple generated candidates under the same criterion conditions.



This experiment does not automatically select the final answer.



It measures.



Applications decide.



\---



\## Pipeline



User Objective

↓



Candidate Generation

↓



Geometric Evaluation



Measure:



\- semantic field

\- origin cost

\- objective alignment

\- orientation

\- preservation

\- drift



↓



Candidate Ranking



↓



Application Decision



\---



\## Outputs



Each candidate produces:



{

score,

field,

origin\_cost,

objective\_bonus,

orientation,

preservation,

decision

}



\---



\## Principle



Selection is application logic.



Criterion measurement belongs to ACA.
