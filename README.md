\# ACA Runtime



Geometry-based criterion supervision for semantic runtime evaluation.



ACA Runtime evaluates semantic orientation using persistent geometric fields generated by the ACA Atlas framework.



Instead of reconstructing criterion through repeated prompting, ACA Runtime externalizes semantic supervision into reusable vector topology.



\---



\# Core Concept



ACA Runtime computes semantic alignment through geometric projection:



O(z) = ||v - P\_S(v)||²



Where:



\- v = embedding vector

\- S = semantic field subspace

\- P\_S(v) = projection onto the field



Lower origin cost indicates stronger semantic alignment.



\---



\# Features



\- Semantic field selection

\- Origin cost evaluation

\- Ambiguity detection

\- Drift supervision

\- Runtime policy decisions

\- Criterion confidence estimation

\- Persistent geometric artifacts



\---



\# Runtime Policies



| Policy | Meaning |

|---|---|

| ALLOW | Stable semantic alignment |

| ALLOW\_LIGHT | Mild ambiguity |

| CLARIFY | Clarification recommended |

| AMBIGUOUS\_CLARIFY | Unstable semantic transition |

| FLAG\_DRIFT | Semantic drift detected |

| AMBIGUOUS\_DRIFT | High entropy / undefined orientation |
